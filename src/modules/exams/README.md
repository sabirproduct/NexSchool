# Examination & Result Management Module

Production-oriented exam ecosystem with exam scheduling, marks entry, grade/GPA logic, result publishing workflow, report card generation, rankings, and analytics.

## Included Capabilities
- Exam dashboard cards and analytics charts.
- Exam CRUD-oriented listing + status lifecycle placeholders.
- Subject-wise schedule tables with class/section breakdown.
- Marks entry grid with absent/exempted state.
- Percentage + grade point computation hooks.
- Result cards, ranking table, and GPA trend chart.
- Report card generation placeholders (PDF/Print/QR verify).
- Cloud Functions placeholders for publishing, ranking, analytics, notifications.

## Firestore Collections
- exams
- examSchedules

- results
