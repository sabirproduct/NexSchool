# Academic Management Module

Includes dashboard, sessions, classes, sections, subjects, teacher assignments, timetable, periods, calendar, and curriculum/homework placeholders.

## Firestore Collections
- academicSessions
- classes
- sections
- subjects
- classSubjects
- teacherAssignments
- timetables
- periods
- academicCalendar
- homework
- curriculum

## Cloud Functions
- detectTimetableConflict
- calculateTeacherWorkload
- validateSessionActivation
- sendAcademicReminders
